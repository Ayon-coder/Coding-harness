Let's implement a **binary tree sort** using a linked list structure. This approach involves:

1. Building a binary search tree (BST) by inserting nodes.
2. Performing an in-order traversal to retrieve elements in sorted order.

Here's the implementation:

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

class BinarySearchTree:
    def __init__(self):
        self.root = None

    def insert(self, value):
        if self.root is None:
            self.root = Node(value)
        else:
            self._insert_recursive(self.root, value)

    def _insert_recursive(self, node, value):
        if value < node.value:
            if node.left is None:
                node.left = Node(value)
            else:
                self._insert_recursive(node.left, value)
        else:
            if node.right is None:
                node.right = Node(value)
            else:
                self._insert_recursive(node.right, value)

    def in_order_traversal(self):
        result = []
        self._traverse(self.root, result)
        return result

    def _traverse(self, node, result):
        if node:
            self._traverse(node.left, result)
            result.append(node.value)
            self._traverse(node.right, result)

# Example usage
bst = BinarySearchTree()
data = [5, 3, 7, 2, 4, 8]
for item in data:
    bst.insert(item)

sorted_data = bst.in_order_traversal()
print("Sorted data:", sorted_data)
```

**Output:**
```
Sorted data: [2, 3, 4, 5, 7, 8]
```

### Key Concepts:
- **Binary Search Tree (BST):** Nodes are inserted such that left children are smaller and right children are larger.
- **In-order Traversal:** Visits nodes in ascending order, producing a sorted list.
